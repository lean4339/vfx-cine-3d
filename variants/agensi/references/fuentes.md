# Bibliografía comentada y alcance de la consulta

Investigación: 3 de noviembre de 2026. Fuentes primarias: autores, editoriales, fabricantes y proyectos. Se enlazan los manuales; no se redistribuyen libros comerciales.

**Estados:** contenido = se consultó contenido técnico accesible, no necesariamente todo el manual; extracto = contenido servido por el índice del buscador; índice = se verificaron secciones; ficha = existencia y alcance editorial, sin lectura integral. Varios accesos directos a Blender devolvieron errores del navegador de investigación: se usaron extractos indexados y se explicita cuando la consulta fue a otra localización. Eso no significa que Blender cobre por el manual.

## Cómo seguir investigando

Para implementar una opción, ir de esta bibliografía a la sección y versión exactas. Si una traducción diverge, comparar con el original y con el programa. Para libros con ficha o índice solamente, obtener acceso legítimo antes de dar una cita textual, una página o atribuirles un procedimiento. Las fechas del buscador no sustituyen el año editorial.

Recorrido sugerido: S16 para leer luz; S02–S07 para construir y deformar; S09–S11 para organizar cuadros; S19–S20 para cámara; S23–S26 para integrar. S01, S08, S15, S17, S18 y S25 amplían el oficio artístico; S12 y S21 profundizan la matemática. Es una propuesta de estudio, no un requisito para empezar un efecto sencillo.
