# VFX · Cine & 3D — multitienda

**Planificar, construir y revisar efectos según lo que necesita cada plano.**

[English](README.md) · **Español**

Una skill de producción e investigación para efectos sobre video, escenas 3D y animación. Parte de lo que debe percibir el espectador, elige la técnica apropiada y pide evidencia visual antes de dar un resultado por terminado.

Esta carpeta conserva la edición multitienda. Su SKILL.md y sus condiciones corresponden a esta copia; las funciones descritas para la raíz pueden diferir.

[Vista general del repositorio](../../README.es.md)

## Qué cubre

| Área | Guía |
| --- | --- |
| Forma y movimiento | Escultura, topología, materiales, rigging, actuación, animación cuadro a cuadro y stop motion. |
| Integración del plano | Tracking, cámara, luz, simulación, render, color y composición. |
| Retoque focalizado | Efectos faciales y dentales con atención a identidad, expresión, contacto y continuidad temporal. |

## Primeros pasos

Leé [SKILL.md](SKILL.md) y después las referencias pertinentes. Dale a un agente compatible acceso al paquete y a los archivos autorizados. Conservá las carpetas adyacentes a SKILL.md; copiar solamente ese archivo puede romper sus referencias.

### Requisitos

Un agente compatible, metraje o escenas autorizados y las herramientas apropiadas. Confirmar versión del programa, fps, rango de cuadros, resolución y tratamiento de color antes de ejecutar.

### Ejemplo de pedido

> Usá vfx-cine-3d para planificar este plano: inspeccioná el metraje, elegí entre 2D y 3D, identificá la incertidumbre principal y proponé una vista previa breve para comprobarla.

## Alcance y límites

El paquete no incluye metraje, recursos 3D, programas de render ni resultados medidos. Un comando exitoso no demuestra calidad visual. La bibliografía distingue material consultado de referencias bibliográficas; esta documentación no revalida APIs externas.

El README está disponible en inglés y español, como la documentación de Huella. Los SKILL.md y las referencias conservan su idioma y redacción originales.
