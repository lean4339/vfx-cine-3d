# VFX · Cine & 3D — multitienda

**Plan, build and inspect effects around the needs of a shot.**

**English** · [Español](README.es.md)

A production and research skill for video effects, 3D scenes and animation. It starts with what the viewer should perceive, chooses an appropriate technique and asks for visual evidence before calling a result finished.

This directory preserves the multitienda edition. Its own SKILL.md and terms are authoritative for this snapshot; features described for the repository root may differ.

[Repository overview](../../README.md)

## What it covers

| Area | Guidance |
| --- | --- |
| Shape and motion | Sculpting, topology, materials, rigging, performance, frame-by-frame animation and stop motion. |
| Shot integration | Tracking, camera, light, simulation, rendering, color and compositing. |
| Focused retouching | Facial and dental effects with attention to identity, expression, contact and temporal consistency. |

## Start here

Read [SKILL.md](SKILL.md), then the references relevant to the task. Give a compatible agent access to this package and the authorized target files. Keep adjacent directories with SKILL.md; copying that file alone can break its references.

### Requirements

A compatible agent, authorized footage or scene files and tools appropriate to the requested work. Confirm software version, frame rate, frame range, resolution and color handling before execution.

### Example request

> Use vfx-cine-3d to plan this shot: inspect the footage, choose between 2D and 3D, identify the hardest uncertainty and propose a short preview that can verify it.

## Scope and limits

The package does not include footage, 3D assets, rendering software or measured results. A successful command is not evidence of visual quality. The bundled bibliography distinguishes consulted material from bibliographic references; this documentation does not revalidate external APIs.

The README is available in English and Spanish, matching Huella’s documentation. Original SKILL.md files and references retain their source language and wording.
